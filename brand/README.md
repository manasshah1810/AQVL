# AQVL brand

`aqvl-logosheet.png` is the reference logo sheet. The chosen mark is **B, "launch loop"**: one continuous stroke that loops (the tangle you can't track) and leaves along a straight baseline (clarity). The wordmark's Q is the same mark at cap height.

| File | Use |
|---|---|
| `aqvl-logosheet.png` | The full sheet: concepts, lockups, small sizes, geometry |
| `aqvl-symbol.svg` | Mark, peach on transparent |
| `aqvl-symbol-light.svg` | Mark for light backgrounds |
| `aqvl-symbol-onecolor.svg` | Single-colour mark |
| `aqvl-wordmark.svg`, `aqvl-wordmark-onecolor.svg` | Wordmark |
| `aqvl-lockup.svg`, `aqvl-lockup-on-twilight.svg`, `aqvl-lockup-onecolor.svg` | Mark + wordmark |

The website draws the mark from code: `packages/demo/src/brand/geometry.ts` (stroke 11 on a 100-unit grid, r = 30, 40° gap).

Site palette: `#1E1C27` base, `#ebc0a3` text and hairlines, `#3A3649` panels, `#666379` accent, `#F5D8C6` highlight.
